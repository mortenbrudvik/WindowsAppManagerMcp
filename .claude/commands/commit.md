# Commit

Create a versioned release commit with tag for the Windows App Manager plugin.

## Usage

```
/commit [version] [message]
```

- `version` (optional): Version number (e.g., `1.2.0`). If not provided, will prompt for it.
- `message` (optional): Brief description of changes. If not provided, will prompt for it.

## Process

When invoked, perform these steps:

### 1. Gather Information

If version or message not provided as arguments, ask the user:
- **Version**: What version number? (e.g., 1.2.0)
- **Message**: Brief description of the changes (1-2 sentences)

### 2. Update Version Numbers

Update version in these files:
- `.claude-plugin/plugin.json` (line 3, `"version": "X.X.X"`)
- `.claude-plugin/marketplace.json` (line 11, `"version": "X.X.X"`)

### 3. Review Changes

Run `git status` and `git diff --stat` to show the user what will be committed.

### 4. Commit and Tag

```bash
# Stage all changes
git add -A

# Commit with conventional commit format
git commit -m "feat: <message>

- <auto-generated bullet points summarizing key changes>
- Bump version to <version>



# Create annotated tag
git tag -a v<version> -m "Release v<version> - <message>"
```

### 5. Push

```bash
git push && git push --tags
```

### 6. Confirm

Display:
- Commit hash
- Tag name
- GitHub release URL: `https://github.com/mortenbrudvik/WindowsAppManagerMcp/releases/tag/v<version>`

## Example

```
/commit 1.2.0 "Add window grouping feature"
```

Results in:
- Version updated to 1.2.0 in plugin files
- Commit: `feat: Add window grouping feature`
- Tag: `v1.2.0`
- Pushed to origin
